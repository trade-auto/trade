# 트레이딩 차트 애플리케이션

## 개요
이 애플리케이션은 암호화폐 트레이딩을 위한 차트 및 분석 도구를 제공합니다. 볼린저 밴드 전략과 A15 기울기 필터 전략을 기반으로 매수/매도 신호를 분석하고 시각화합니다.

## 주요 기능
- 실시간 캔들스틱 차트 표시
- 이동평균선(MA) 표시 및 설정
- 자동 업데이트 및 실시간 API 연동
- 백테스트 기능 (CSV 데이터 임포트/내보내기)
- 트레이딩 전략 분석 및 신호 표시

## 컴포넌트 구조

### CandlestickChartCore
메인 차트 컴포넌트로, 다음 기능을 제공합니다:
- 차트 데이터 표시 및 관리
- 자동 업데이트 설정
- 백테스트 결과 표시
- CSV 데이터 관리

### 주요 훅(Hooks)
- `useChartData`: 차트 데이터 및 기능 관리
- `useCsvFunctions`: CSV 데이터 임포트/내보내기 기능
- `useBacktestChart`: 백테스트 차트 관리

## 트레이딩 전략

### 볼린저 밴드 전략

#### 매수 조건
1. **MA240이 5봉 이상 연속 상향**: 240기간 이동평균선이 5개 이상 연속으로 상승세
2. **MA60 > MA120**: 60기간 이동평균선이 120기간 이동평균선보다 위에 위치
3. **MA60 > MA240**: 60기간 이동평균선이 240기간 이동평균선보다 위에 위치
4. **MA600 상승세**: 600기간 이동평균선이 상승세 (현재 MA600 > 이전 MA600)
5. **MA60 < MA600** (선택적 조건): 60기간 이동평균선이 600기간 이동평균선보다 아래에 위치

#### 매도 조건
1. **MA240이 5봉 이상 연속 하향**: 240기간 이동평균선이 연속적으로 5개 이상의 봉에서 하강세를 보여야 합니다.
2. **MA60 < MA120**: 60기간 이동평균선이 120기간 이동평균선보다 아래에 있어야 합니다.
3. **MA60 < MA240**: 60기간 이동평균선이 240기간 이동평균선보다 아래에 있어야 합니다.
4. **MA600 하강세**: 600기간 이동평균선이 하강세를 보여야 합니다 (현재 MA600 < 이전 MA600).

### A15 기울기 필터 전략 (Slope Filter Strategy)

A15 기울기 필터 전략은 이동평균선(MA)과 기울기를 활용한 트레이딩 전략입니다. 이 전략은 다양한 기간의 이동평균선 간의 관계와 기울기를 분석하여 매수 및 매도 시점을 결정합니다.

#### 주요 지표

- **MA60**: 60초 이동평균선
- **MA120**: 120초 이동평균선
- **MA240**: 240초 이동평균선
- **MA360**: 360초 이동평균선
- **MA600**: 600초 이동평균선

#### 매수 조건

매수 신호는 다음 조건이 모두 충족될 때 발생합니다:

1. **마지막 거래가 매수가 아님**: `store.tradeState.lastTradeType !== 'bid'` 이고

2. **다음 조건 중 하나 충족**:
   - **조건 A (정배열 조건)**:
     - **MA60이 MA120보다 위에 위치**
     - **MA60이 MA240보다 위에 위치**
     - **MA60이 MA360보다 위에 위치**
     - **MA120, MA240, MA360이 모두 양의 기울기**
     - **완전 정배열**: MA60 > MA120 > MA240
   - **조건 B (MA 수렴 조건)**:
     - **MA120, MA240, MA360이 서로 가까이 있음** (편차 0.5% 이내)
     - **MA120, MA240, MA360이 모두 양의 기울기**
     - **MA60이 MA120보다 위에 위치**

3. **MA60이 MA600 아래에 위치**: 중장기 이동평균선(MA600) 아래에서만 매수

4. **MA600 기울기가 양수**: 중장기 이동평균선(MA600)의 기울기가 상승 중일 때만 매수

5. **매수 가능 상태**: `store.tradeState.theoreticalPosition === 'wait'`

#### 매도 조건

매도 신호는 다음 조건 중 하나가 충족될 때 발생합니다:

1. **다음 중 하나 이상 충족**:
   - **완전 역배열**: MA60 < MA120 < MA240 또는
   - **완전 정배열이면서 MA60이 다른 MA 아래에 위치**: MA60 > MA120 > MA240 이고
     - **MA60이 MA120 아래에 위치**
     - **MA60이 MA240 아래에 위치**
     - **MA60이 MA360 아래에 위치**
     - **MA60이 MA600 아래에 위치**

2. **또는 MA600 하락 중**: MA600의 각도가 0보다 작음 (하락 추세)

#### 각도 계산 방법

MA의 기울기를 각도로 변환하는 방법:

1. 기울기 계산: `slope = currentMA - previousMA`
2. 각도 계산(라디안): `angleRaw = Math.atan(slope)`
3. 각도 변환(도): `angle = angleRaw * (180 / Math.PI)`

#### 주의사항

- 충분한 데이터가 있어야 전략이 제대로 작동합니다(최소 600초).
- 매수 후 최소 60초는 매도 신호를 발생시키지 않습니다.
- 매수/매도 신호 간 최소 30초의 간격이 있습니다.

## 최근 수정사항

### A15 기울기 필터 전략 업데이트
- **매수 조건 개선**: 
  - MA600 상승 조건을 제거하고 MA60이 MA120, MA240, MA360을 상방 관통하는 조건으로 변경
  - MA60이 MA120, MA240, MA360보다 위에 위치하는 조건으로 변경 (상방 관통 조건에서 수정)
  - MA120, MA240, MA360이 모두 양의 기울기를 가져야 함
  - 완전 정배열 조건 유지 (MA60 > MA120 > MA240)
  - MA120, MA240, MA360이 서로 가까이 있을 때(편차 0.5% 이내)의 매수 조건 추가
  - MA60이 MA600 아래에 있어야 한다는 조건 추가 (중장기 이동평균선 아래에서만 매수)
  - MA600 기울기가 양수여야 한다는 조건 추가 (중장기 이동평균선이 상승 중일 때만 매수)
- **매도 조건 개선**: 
  - 완전 역배열 또는 완전 정배열이면서 MA60이 MA120, MA240, MA360, MA600 아래에 위치하는 조건으로 변경
  - MA600 하락 조건 유지

### backtestMarkers 문제 해결
백테스트 차트에서 마커(매수/매도 신호)를 표시하기 위한 `backtestMarkers` 변수가 정의되지 않아 발생한 오류를 수정했습니다.

```javascript
// 백테스트 마커 추출
const backtestMarkers = csvBacktestResult?.markers || [];
```

이 코드는 CSV 백테스트 결과에서 마커 데이터를 추출하거나, 결과가 없는 경우 빈 배열을 사용합니다.

## AB1 매매 조건

### 매수 조건
1. MACD가 -20% 이하에서
2. MACD가 시그널선을 상향돌파
3. 5EMA가 20EMA를 상향돌파
4. 이전 신호가 없거나 매도였을 때

### 매도 조건
1. MACD가 +10% 이상에서
2. MACD가 시그널선을 하향돌파
3. 이전 신호가 매수였을 때

### 제한 조건
- MACD가 -20% ~ +10% 구간에서는 매매 신호 발생하지 않음
- 360일 이동평균선 위에서는 매도 신호 무시 (안전장치)
- 매수 포지션 중에는 새로운 매수 신호 무시
- 매도 포지션 중에는 새로운 매도 신호 무시

### 수수료
- 매수/매도 각각 0.05% (총 0.1%)

### 투자 규모
- 최대 주문 금액의 25% 사용

## AB2 매매 전략 (AB2 Trading Strategy)

### 기본 지표
- MACD (23, 25, 11)
- EMA (5, 20, 30, 48)

### 매수 조건 (Buy Signal)
1. MACD가 -10% 이하 구간에서
2. 다음 조건 중 하나를 만족할 때:
   - MACD가 시그널선을 상향돌파
   - 5 EMA가 20 EMA를 상향돌파
3. 20 EMA가 상승 중일 때

### 매도 조건 (Sell Signal)
1. MACD가 시그널선을 하향돌파할 때
2. 이전에 매수 포지션이 있을 때

### 추가 참고사항
- MACD 범위:
  - 상단: +15% 레벨
  - 하단: -10% 레벨
- EMA 활용:
  - 5 EMA: 단기 추세
  - 20 EMA: 중기 추세
  - 30 EMA: 중장기 추세
  - 48 EMA: 장기 추세

### 리스크 관리
- 매수 시점: MACD가 -10% 이하 구간에서만 매수하여 리스크 최소화
- 매도 시점: MACD가 시그널선을 하향돌파하는 즉시 매도하여 수익 실현
- 손절: 별도의 손절 라인은 없으며, MACD 하향돌파 시 매도

### 전략 특징
1. 과매도 구간에서의 반등을 노리는 매수 전략
2. MACD와 EMA 크로스를 활용한 이중 확인
3. 빠른 수익 실현을 위한 즉각적인 매도 시그널
4. 20 EMA 상승 조건으로 상승 추세 확인

# AB2 매매 전략 상세 가이드

## 1. 기본 지표 설정
### MACD 설정
- 기준선(MACD): EMA 23 - EMA 25
- 신호선: MACD의 11일 EMA
- 히스토그램: MACD - 신호선

### 이동평균선 설정
- 단기: 5 EMA (파란색)
- 중기: 20 EMA (빨간색)
- 중장기: 30 EMA (주황색)
- 장기: 48 EMA (초록색)

## 2. 매수 조건 (Buy Signal)
### 필수 조건
1. MACD가 -10% 레벨 이하에 위치
2. 20 EMA가 상승 추세일 것 (현재값 > 이전값)

### 진입 트리거 (둘 중 하나 만족)
1. MACD 크로스
   - MACD가 시그널선을 상향돌파
   - 이전 캔들: MACD <= 시그널선
   - 현재 캔들: MACD > 시그널선

2. EMA 크로스
   - 5 EMA가 20 EMA를 상향돌파
   - 이전 캔들: 5 EMA <= 20 EMA
   - 현재 캔들: 5 EMA > 20 EMA

### 추가 확인사항
- 이전 매수 신호 이후 매도가 발생했을 것
- 과매수 구간(+15% 이상)이 아닐 것

## 3. 매도 조건 (Sell Signal)
### 필수 조건
1. 이전에 매수 포지션이 있을 것
2. MACD가 시그널선을 하향돌파
   - 이전 캔들: MACD > 시그널선
   - 현재 캔들: MACD <= 시그널선

### 매도 타이밍
- 즉각 매도: MACD가 시그널선을 하향돌파하는 즉시 매도
- 추가 홀딩 없음: 다른 보조지표 확인하지 않음

## 4. 리스크 관리
### 매수 리스크 관리
1. 과매도 구간(-10% 이하)에서만 매수
   - 하락 추세의 바닥권 매수로 리스크 최소화
   - 반등 가능성이 높은 구간에서 진입
2. 20 EMA 상승 확인
   - 상승 추세 확인으로 잘못된 매수 신호 필터링
   - 추세 추종형 매수로 리스크 감소

### 매도 리스크 관리
1. 즉각 매도 원칙
   - MACD 하향돌파 즉시 매도로 손실 최소화
   - 추가 하락 대비
2. 부분 매도 없음
   - 전량 매도로 포지션 정리
   - 불필요한 홀딩 리스크 제거

## 5. 전략 특징
1. 반등 매매
   - 과매도 구간에서 반등 시점 포착
   - 상승 추세 전환 확인 후 진입
2. 듀얼 크로스 시스템
   - MACD 크로스와 EMA 크로스 활용
   - 이중 확인으로 신뢰도 향상
3. 빠른 수익 실현
   - 즉각적인 매도로 수익 실현
   - 추가 상승 포기로 안정적 수익 추구
4. 추세 추종
   - 20 EMA 상승 확인으로 상승 추세 참여
   - 하락 전환 시 즉시 탈출

## 6. 주의사항
1. 과매수/과매도 레벨
   - 과매수: MACD +15% 레벨
   - 과매도: MACD -10% 레벨
   - 레벨은 전체 MACD 범위 기준으로 동적 계산

2. 매매 제한 구간
   - MACD가 -10% ~ +15% 구간에서는 새로운 매수 신호 무시
   - 단, 매도 신호는 모든 구간에서 유효

3. EMA 활용
   - 5 EMA: 단기 방향성 판단
   - 20 EMA: 중기 추세 확인
   - 30 EMA: 중장기 추세 참고
   - 48 EMA: 장기 추세 참고

# AB2 매도 조건 상세 가이드

## 1. 기본 매도 조건
### 필수 전제 조건
- 현재 매수 포지션을 보유하고 있을 것
- 이전 매도 신호 이후 새로운 매수가 있었을 것

### 매도 트리거 조건
1. MACD 하향돌파
   - 이전 캔들: MACD > 시그널선
   - 현재 캔들: MACD <= 시그널선
   - 하향돌파 즉시 매도 실행

## 2. 매도 실행 원칙
### 즉각 매도 원칙
- MACD 하향돌파 확인 즉시 매도
- 추가 지표 확인 없이 즉시 청산
- 전량 매도 원칙 (부분 매도 없음)

### 매도 제외 조건
- 없음 (모든 가격대에서 매도 신호 유효)
- 과매수/과매도 구간 상관없이 매도

## 3. 매도 시점별 특징
### 과매수 구간 매도 (+15% 이상)
- 일반적으로 큰 수익 실현 구간
- 상승 추세 전환 가능성 높음
- 매도 신호 발생 시 즉시 매도

### 중립 구간 매도 (-10% ~ +15%)
- 일반적인 수익 실현 구간
- 추세 전환 가능성 있음
- 매도 신호 발생 시 즉시 매도

### 과매도 구간 매도 (-10% 이하)
- 손실 최소화 구간
- 하락 추세 가속화 가능성 높음
- 매도 신호 발생 시 즉시 매도

## 4. 매도 후 행동
### 재진입 제한
- 매도 후 즉시 재진입 금지
- 새로운 매수 신호 대기
- 과매도 구간(-10% 이하) 도달 대기

### 다음 매수 준비
- MACD -10% 레벨 이하 도달 관찰
- 20 EMA 상승 전환 대기
- 새로운 매수 신호 대기

## 5. 매도 리스크 관리
### 손실 관리
- 별도의 손절가 없음
- MACD 하향돌파를 손절 시점으로 활용
- 추가 하락 방지를 위한 즉각 매도

### 수익 관리
- 목표가 설정 없음
- 상승 추세 유지 시 포지션 유지
- MACD 하향돌파 시 수익 실현

## 6. 매도 전략의 장단점
### 장점
- 명확한 매도 시점
- 감정 배제된 기계적 매매
- 빠른 손절로 손실 최소화
- 추세 추종으로 수익 극대화

### 단점
- 추가 상승 시 기회비용 발생
- 일시적 하락에도 매도 발생
- 잦은 매매 가능성
- 수수료 비용 증가

## 7. 매도 실행 체크리스트
1. 매수 포지션 보유 확인
2. MACD 하향돌파 확인
   - 이전 캔들 MACD > 시그널선
   - 현재 캔들 MACD <= 시그널선
3. 즉시 전량 매도 실행
4. 재진입 제한 적용
5. 다음 매수 기회 대기
