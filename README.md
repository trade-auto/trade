# 트레이딩 차트 애플리케이션

## 개요
이 애플리케이션은 암호화폐 트레이딩을 위한 차트 및 분석 도구를 제공합니다. 볼린저 밴드 전략과 A15 기울기 필터 전략을 기반으로 매수/매도 신호를 분석하고 시각화합니다.

## 주요 기능
- 실시간 캔들스틱 차트 표시
- 이동평균선(MA) 표시 및 설정
- 자동 업데이트 및 실시간 API 연동
- 백테스트 기능 (CSV 데이터 임포트/내보내기)
- 트레이딩 전략 분석 및 신호 표시

## 컴포넌트 구조

### CandlestickChartCore
메인 차트 컴포넌트로, 다음 기능을 제공합니다:
- 차트 데이터 표시 및 관리
- 자동 업데이트 설정
- 백테스트 결과 표시
- CSV 데이터 관리

### 주요 훅(Hooks)
- `useChartData`: 차트 데이터 및 기능 관리
- `useCsvFunctions`: CSV 데이터 임포트/내보내기 기능
- `useBacktestChart`: 백테스트 차트 관리

## 트레이딩 전략

### 볼린저 밴드 전략

#### 매수 조건
1. **MA240이 5봉 이상 연속 상향**: 240기간 이동평균선이 5개 이상 연속으로 상승세
2. **MA60 > MA120**: 60기간 이동평균선이 120기간 이동평균선보다 위에 위치
3. **MA60 > MA240**: 60기간 이동평균선이 240기간 이동평균선보다 위에 위치
4. **MA600 상승세**: 600기간 이동평균선이 상승세 (현재 MA600 > 이전 MA600)
5. **MA60 < MA600** (선택적 조건): 60기간 이동평균선이 600기간 이동평균선보다 아래에 위치

#### 매도 조건
1. **MA240이 5봉 이상 연속 하향**: 240기간 이동평균선이 연속적으로 5개 이상의 봉에서 하강세를 보여야 합니다.
2. **MA60 < MA120**: 60기간 이동평균선이 120기간 이동평균선보다 아래에 있어야 합니다.
3. **MA60 < MA240**: 60기간 이동평균선이 240기간 이동평균선보다 아래에 있어야 합니다.
4. **MA600 하강세**: 600기간 이동평균선이 하강세를 보여야 합니다 (현재 MA600 < 이전 MA600).

### A15 기울기 필터 전략 (Slope Filter Strategy)

A15 기울기 필터 전략은 이동평균선(MA)과 기울기를 활용한 트레이딩 전략입니다. 이 전략은 다양한 기간의 이동평균선 간의 관계와 기울기를 분석하여 매수 및 매도 시점을 결정합니다.

#### 주요 지표

- **MA60**: 60초 이동평균선
- **MA120**: 120초 이동평균선
- **MA240**: 240초 이동평균선
- **MA360**: 360초 이동평균선
- **MA600**: 600초 이동평균선

#### 매수 조건

매수 신호는 다음 조건이 모두 충족될 때 발생합니다:

1. **마지막 거래가 매수가 아님**: `store.tradeState.lastTradeType !== 'bid'` 이고

2. **다음 조건 중 하나 충족**:
   - **조건 A (정배열 조건)**:
     - **MA60이 MA120보다 위에 위치**
     - **MA60이 MA240보다 위에 위치**
     - **MA60이 MA360보다 위에 위치**
     - **MA120, MA240, MA360이 모두 양의 기울기**
     - **완전 정배열**: MA60 > MA120 > MA240
   - **조건 B (MA 수렴 조건)**:
     - **MA120, MA240, MA360이 서로 가까이 있음** (편차 0.5% 이내)
     - **MA120, MA240, MA360이 모두 양의 기울기**
     - **MA60이 MA120보다 위에 위치**

3. **MA60이 MA600 아래에 위치**: 중장기 이동평균선(MA600) 아래에서만 매수

4. **MA600 기울기가 양수**: 중장기 이동평균선(MA600)의 기울기가 상승 중일 때만 매수

5. **매수 가능 상태**: `store.tradeState.theoreticalPosition === 'wait'`

#### 매도 조건

매도 신호는 다음 조건 중 하나가 충족될 때 발생합니다:

1. **다음 중 하나 이상 충족**:
   - **완전 역배열**: MA60 < MA120 < MA240 또는
   - **완전 정배열이면서 MA60이 다른 MA 아래에 위치**: MA60 > MA120 > MA240 이고
     - **MA60이 MA120 아래에 위치**
     - **MA60이 MA240 아래에 위치**
     - **MA60이 MA360 아래에 위치**
     - **MA60이 MA600 아래에 위치**

2. **또는 MA600 하락 중**: MA600의 각도가 0보다 작음 (하락 추세)

#### 각도 계산 방법

MA의 기울기를 각도로 변환하는 방법:

1. 기울기 계산: `slope = currentMA - previousMA`
2. 각도 계산(라디안): `angleRaw = Math.atan(slope)`
3. 각도 변환(도): `angle = angleRaw * (180 / Math.PI)`

#### 주의사항

- 충분한 데이터가 있어야 전략이 제대로 작동합니다(최소 600초).
- 매수 후 최소 60초는 매도 신호를 발생시키지 않습니다.
- 매수/매도 신호 간 최소 30초의 간격이 있습니다.

## 최근 수정사항

### A15 기울기 필터 전략 업데이트
- **매수 조건 개선**: 
  - MA600 상승 조건을 제거하고 MA60이 MA120, MA240, MA360을 상방 관통하는 조건으로 변경
  - MA60이 MA120, MA240, MA360보다 위에 위치하는 조건으로 변경 (상방 관통 조건에서 수정)
  - MA120, MA240, MA360이 모두 양의 기울기를 가져야 함
  - 완전 정배열 조건 유지 (MA60 > MA120 > MA240)
  - MA120, MA240, MA360이 서로 가까이 있을 때(편차 0.5% 이내)의 매수 조건 추가
  - MA60이 MA600 아래에 있어야 한다는 조건 추가 (중장기 이동평균선 아래에서만 매수)
  - MA600 기울기가 양수여야 한다는 조건 추가 (중장기 이동평균선이 상승 중일 때만 매수)
- **매도 조건 개선**: 
  - 완전 역배열 또는 완전 정배열이면서 MA60이 MA120, MA240, MA360, MA600 아래에 위치하는 조건으로 변경
  - MA600 하락 조건 유지

### backtestMarkers 문제 해결
백테스트 차트에서 마커(매수/매도 신호)를 표시하기 위한 `backtestMarkers` 변수가 정의되지 않아 발생한 오류를 수정했습니다.

```javascript
// 백테스트 마커 추출
const backtestMarkers = csvBacktestResult?.markers || [];
```

이 코드는 CSV 백테스트 결과에서 마커 데이터를 추출하거나, 결과가 없는 경우 빈 배열을 사용합니다.

## 콘솔 로그 관리
차트 업데이트 중 콘솔 창이 리셋되는 문제가 있을 수 있습니다. 이는 많은 로그 출력으로 인한 것으로, 필요한 경우 로그 출력을 제한하거나 특정 로그만 표시하도록 설정할 수 있습니다.
